The docs/ tree is organized by concern rather than by product layer, with five sibling areas that together form the project's spec-driven development lifecycle: `adr/` holds immutable architectural decision records that supersede long-form docs; `specs/SPEC-NNN-*` are numbered feature specifications each containing plan.md/spec.md/tasks.md that implement those decisions; `agentic-aiops-platform/` contains higher-level design documents (reference architecture, identity/auth, policy spec, delivery roadmap) plus milestone-oriented release notes in `release-notes/`; `guides/` provides end-user and operator-facing how-to documentation; `workspace/` captures pre-spec technical spikes, product boundary definitions, and repository governance. The numbering across ADRs (0001–0014), SPECs (001–068), and release notes (dated filenames) creates a cross-referenced timeline linking architectural intent to implemented features and shipped releases.
