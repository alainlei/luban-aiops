Single-abstract-base design centered on `base.AgentScopeProvider` (ABC), which defines the provider contract (`provider_name`, `default_model`, `model_series`, `discover_family_prefixes`, `build_model`, `validate`, `resolved_model_name`, `resolved_base_url`) plus shared live-discovery filtering logic that strips dated snapshots and non-chat modalities. Each vendor file (`openai.py`, `dashscope.py`, `deepseek.py`, `luban.py`) subclasses this ABC and wires a specific AgentScope credential + model class. A central `registry.py` holds an in-process `_PROVIDERS` dict keyed by string name and exposes `get_provider()` / `supported_provider_names()`. The package `__init__.py` re-exports only the abstract base, the configuration error type, and the registry accessors — concrete providers are imported lazily inside `build_model` via local imports of `agentscope.credential`/`agentscope.model` to avoid hard dependencies when a provider is unused. Dependency direction: concrete providers → `base` → `agent_service.runtime_settings` (types); nothing in this module imports from higher layers.
