Root workflow is driven by GNU make: `make verify` runs the full pre-commit/pre-push gate (all product tests, kustomize overlay render, dashboard schema validation, policy bundle validation + scenario evaluation, version lockstep check, secret-vocabulary check, password-policy check, acme-admin secret-delivery demo, portal Vitest + production build, and crash-safety failure test). `make build` produces coordinated images tagged `<semver>-[prefix][-profile]-<sha>` and writes `shared/platform-ops/gitops/dev-k8s/.images.env`; `make deploy` applies the dev-k8s overlay; `make e2e` runs the scripted demos against a deployed cluster requiring port-forwards for platform-gateway and identity-broker. Per-product commands are available via `make -C products/<name> help`.
