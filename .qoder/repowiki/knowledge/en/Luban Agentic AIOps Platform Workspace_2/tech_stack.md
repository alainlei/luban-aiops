Python services managed with `uv` (pinning interpreter via `.python-version` and per-product `uv.lock`); FastAPI-based HTTP services containerized with Dockerfiles built through `mk/image.mk`; Kubernetes deployment via kustomize overlays; operator portal is a Node/Vite SPA served by nginx; policy evaluation uses JSON-schema-backed YAML bundles validated by scripts in `shared/shared-contracts/scripts/`.
