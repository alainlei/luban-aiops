Python backend services managed by `uv` (per-product `pyproject.toml` + `uv.lock`, pinned via `.python-version`); container images built with Dockerfiles using a shared `shared/base-images/base-uv` base image; Kubernetes deployment via Kustomize overlays under `shared/platform-ops/gitops`; operator portal is a Node.js SPA behind Nginx; end-to-end demos run against a local `kind` cluster.
