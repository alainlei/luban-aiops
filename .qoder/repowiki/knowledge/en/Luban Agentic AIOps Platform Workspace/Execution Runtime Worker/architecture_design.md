The service is a FastAPI application (`app.py` + `main.py`) exposing two route groups under `api/routes/`: `/api/v1/executions/handoff` (admission + execution) and health endpoints. The HTTP layer delegates to layered services in `services/`: `executor.py` performs the one-shot outbound call to the tool gateway via httpx; `execution_protocol.py` centralizes Draft202012 JSON-Schema validation of all wire envelopes loaded from `contracts/*.schema.json` plus HMAC envelope signing/verification through `execution_signing.py`; `execution_ledger.py` owns the PostgreSQL schema (`execution-ledger-v1.sql`) and claim/receipt state machine; `audit_emitter.py`, `execution_io.py`, `single_flight.py`, `execution_cutover.py`, and `execution_records.py` provide supporting concerns (async audit delivery, DB budget/thread ownership, idempotent dispatch, cutover, retention). Configuration flows through `core/config.py` and `core/runtime.py` (frozen dataclass parsed from env), while `core/metrics.py`, `core/telemetry.py`, and `core/observability.py` wire Prometheus counters, OTLP traces, and structured logging. Shutdown is coordinated by a SIGTERM handler in `app.py` that flips an `app.state.draining` flag so new handoffs are refused before uvicorn's graceful drain budget expires. Dependency direction is strictly API → services → core/contracts; contracts are pure JSON schemas consumed at runtime via `importlib.resources`.
