- Each skill sample ships a fixed quartet of artifacts: `README.md` (pattern explanation), `WALKTHROUGH.md` (live click-by-click run), `skill/*.md` (installed document), and `demo/demo.sh` (unattended assertion), with `skill-graduation` being the deliberate exception where the skill is produced at runtime.
- Demo scripts use `set -eu`, source `demo-lib.sh` via `CDPATH= cd -- "$(dirname -- "$0")" && pwd` followed by `. "$SUITE_DIR/demo-lib.sh"`, and fail fast with descriptive messages rather than returning non-zero codes.
- Skill ids are derived deterministically from the mounted filename: `<leaf>-<relpath-with-slashes-dashed>.md` becomes a ConfigMap key, then lowercased with non-alphanumerics collapsed to `-` to form `samples/<slug>`; file names are chosen to avoid collisions across categories.
- The acme-admin app enforces a fail-closed startup contract: missing `ACME_ADMIN_PASSWORD` raises `RuntimeError` with a message naming the secret and sync script, and OpenAPI/docs/redoc URLs are explicitly disabled to avoid exposing the header-gated `/internal/reset-demo` endpoint.
- Cross-surface verification is asserted end-to-end: mutations made through `http.post` against the JSON API are read back from the rendered HTML table (same revision, same `data-locked` attribute), proving both surfaces address one in-memory store rather than a shared cache.
