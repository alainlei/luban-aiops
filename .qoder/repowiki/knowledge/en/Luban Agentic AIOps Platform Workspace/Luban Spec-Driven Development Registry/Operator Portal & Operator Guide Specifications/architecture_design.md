Three independent spec directories under `docs/specs/`, each following the repository's SPEC template (`spec.md` + `plan.md` + `tasks.md`) and tracking a single delivery slice:
- `SPEC-019-portal-transparency-navigation/` defines the portal's sectioned sidebar, live permission-matrix endpoint (`GET /api/v1/policy/matrix`), and read-only Tools/Skills workspace views backed by platform-gateway proxies to tool-gateway and skills-hub.
- `SPEC-023-portal-framework-rebuild/` specifies rebuilding the portal on React + Ant Design X + TypeScript via Vite, with a single platform-owned SSE contract adapter translating stream schema v6 frames into typed models; it consumes existing chat/session/audit contracts unchanged and preserves SPEC-019's sectioned navigation.
- `SPEC-012-operator-guide/` specifies the operator documentation surface (`docs/guides/{getting-started,configuration-reference,troubleshooting,tool-configuration,architecture-overview}.md`) bridging developer specs to end-to-end cluster deployment.
Dependency direction is one-way: SPEC-023 builds on SPEC-019's UI contract (sectioned nav, role-scoped visibility) and both consume backend contracts owned by `products/platform-gateway`; SPEC-012 is orthogonal documentation. All three specs are marked `status: delivered` in their metadata headers.
