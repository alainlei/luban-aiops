This module is a documentation-only spec artifact (no source code) defining the migration from two incompatible agent-service wire protocols to one stable `/api/v2/` boundary. It documents five requirements: R-1 defines new JSON Schema files under `shared/shared-contracts/schemas/` (`agent-chat-request`, `agent-chat-response`, `agent-stream-event`, `agent-session`, `agent-runtime-metadata`, `agent-health`) plus header conventions (`X-User-ID`, `x-request-id`); R-2 places an adapter in `agent_service/api/v2/` backed by `AgentKernel` that translates AgentScope internals into contract-conformant dicts; R-3 removes the gateway's dual-backend abstraction (`TransitionalAgentServiceBackend`, `NativeAgentServiceBackend`, `resolve_agent_backend`) in favor of a single `AgentServiceClient`; R-4 retires the transitional FastAPI routes under `/api/v1/`; R-5 enforces bidirectional contract tests via `jsonschema.validate`. The plan prescribes an inside-out sequencing (schemas → adapter → gateway → retirement) and keeps v1/v2 coexistence only during development, with rollback limited to reverting the gateway before R-4.
