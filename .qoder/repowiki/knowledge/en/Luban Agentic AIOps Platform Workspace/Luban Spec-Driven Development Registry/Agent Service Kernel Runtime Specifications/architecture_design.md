The three specs form a layered runtime contract: SPEC-002 establishes the single JSON Schema boundary between the AgentScope LLM kernel and the platform's tool-gateway; SPEC-007 builds on that boundary to describe how tools are invoked through the gateway with policy enforcement and audit; SPEC-017 rounds out the runtime by specifying kernel configuration hardening, triage output structuring, and `AgentState` persistence in Postgres. There is no shared code here — each directory contains its own plan.md/spec.md/tasks.md triplet, and cross-spec wiring is documented rather than enforced at this level.
