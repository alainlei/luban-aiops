This module is a documentation-only leaf under docs/specs/ containing three complementary artifacts for SPEC-007: `spec.md` defines the requirements (R-1 through R-7) covering shared JSON Schema contracts (`tool-invocation.schema.json`, `tool-result.schema.json`), an in-process `ToolRegistry` + `BaseTool` abstraction in tool-gateway, a first `k8s.*` connector using `kubernetes-client/python`, REST routes at `/api/v2/tools`, policy bundle extension granting `tools:invoke`, AgentScope Toolkit wiring in agent-platform, and dev-k8s RBAC. `plan.md` lays out the bottom-up implementation sequence (contracts → registry → connector → routes/policy → agent integration → overlay) and records rejected alternatives (entry_points plugin discovery, raw httpx to K8s API, kubectl subprocess). `tasks.md` decomposes each requirement into executable tasks. The spec explicitly scopes itself to read-only operations (no write/mutating tools, no approval workflow, no MCP server/client, no isolated workers) and defers log redaction until after the first non-dev deployment. Cross-cutting dependencies are tracked against ADR-0002, ADR-0003, and the follow-up SPEC-008 (broker-mediated token delegation) which resolved Q-1/Q-2; the status is `delivered`.
