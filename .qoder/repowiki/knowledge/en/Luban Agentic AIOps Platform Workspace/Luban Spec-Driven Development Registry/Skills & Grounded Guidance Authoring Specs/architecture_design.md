Three sibling spec directories form a single feature family around team-owned Markdown runbooks (skills):
- SPEC-014 defines the `skills-hub` product: federated multi-source Git/local ingestion, Skill Format v1 schema (`shared/shared-contracts/schemas/skill.schema.json`), keyword search API, and the read-only `skills.search` tool registered in tool-gateway.
- SPEC-044 extends it with a client-side skill-draft export: agent-platform generates a fenced `skill-frontmatter` + Markdown from a session digest, skills-hub validates via its existing ingestion path on `POST /api/v1/skills/validate`, and the portal downloads the `.md` for Git contribution — no platform persistence of drafts.
- SPEC-056 reorganizes the portal surface: an additive immutable `session_type` discriminator (`operation` | `development`) on the session contract, splitting one Chat entry into Chat (drafts) and Studio (declare-target + graduate), sharing one `ChatView` parameterized by `mode`.
Dependency direction is strictly forward across specs: SPEC-014 establishes the skill contract and ingestion; SPEC-044 consumes it for export; SPEC-056 re-homes the resulting authoring controls without changing their trust model. Each spec follows the project's plan/spec/tasks triad and tracks status through draft → approved → delivered with a changelog.
