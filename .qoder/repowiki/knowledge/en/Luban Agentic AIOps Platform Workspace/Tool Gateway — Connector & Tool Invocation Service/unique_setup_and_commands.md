`uv`-managed project (`pyproject.toml` + `uv.lock`); entry script `tool-gateway = tool_gateway.main:run` installs a CLI that reads `GATEWAY_HOST`/`GATEWAY_PORT` from env. Development runs with `GATEWAY_REQUIRE_AUTH=false` and `GATEWAY_DEV_USER` to bypass SSO. Browser connector requires `GATEWAY_BROWSER_ENABLED=true` plus a sidecar Chrome DevTools endpoint (`GATEWAY_BROWSER_CDP_ENDPOINT`). Mutating tools (k8s delete, web write tools, http.post, secrets.deliver) are off by default and only register when `GATEWAY_MUTING_TOOLS_ENABLED=true`. Policy bundle is loaded from `GATEWAY_POLICY_PATH` or falls back to the packaged `policies/policy-default.yaml`.
