Entrypoint script `tool-gateway` (from `pyproject.toml [project.scripts]`) runs `tool_gateway.main:run`. Build uses `uv_build` backend with `uv.lock` lockfile; tests run via pytest under `.venv` managed by uv. Runtime toggles are all `GATEWAY_*` env vars (e.g. `GATEWAY_K8S_ENABLED`, `GATEWAY_MUTATING_TOOLS_ENABLED`, `GATEWAY_BROWSER_ENABLED`, `GATEWAY_AUDIT_SERVICE_URL`, `OTEL_ENABLED`).
