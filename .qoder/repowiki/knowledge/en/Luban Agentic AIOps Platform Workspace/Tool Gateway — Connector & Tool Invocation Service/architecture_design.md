Layered FastAPI application with clear separation of concerns:
- Entry point: `main.py` boots uvicorn using `GatewayRunSettings.from_env()`; `app.py` builds a single `FastAPI` instance via `create_app()`, wiring lifespan hooks, request middleware (x-request-id propagation, timing), metrics, telemetry, and the router.
- API layer (`api/`): `router.py` composes three route modules — `health` (readiness/liveness), `tools` (discovery + invoke under `tools:list` / `tools:invoke` / `tools:mutate`), and `secrets` (SPEC-062 delivery redemption). Schemas live in `schemas/api.py`.
- Core infrastructure (`core/`): `config.py` (Pydantic settings from env), `runtime.py` (`GatewayRunSettings`), `metrics.py` (Prometheus RED counters), `observability.py` (structured logging), `telemetry.py` (OTLP push), `request_context.py` (correlation).
- Authorization: `services/policy_engine.py` is a dependency-free YAML bundle evaluator implementing SPEC-004/SPEC-030 action authorization with deny-by-default semantics, loaded once per configured path and cached as a module-level singleton keyed on `_configured_path`; `services/token_verifier.py` performs local JWKS-based bearer validation against `IDENTITY_TOKEN_ISSUER`/`GATEWAY_TOKEN_AUDIENCE`.
- Tool execution framework (`tools/`): `base.py` defines `BaseTool` / `ToolDefinition` / `ToolResult`; `registry.py` holds an in-process dispatch table enforcing risk-tier admission (`allow_mutating` flag gates write/admin tools); each connector (`k8s_connector`, `elastic_connector`, `skills_connector`, `incidents_connector`, `browser_connector`, `http_connector`, `secrets_connector`) implements `register_tools(registry)` and is conditionally wired in `_build_tool_registry()` based on `GATEWAY_*_ENABLED` flags.
- Cross-cutting services: `services/gateway_service.py` orchestrates identity+policy checks around tool invocation; `services/audit_emitter.py` fire-and-forgets `tool_invoked` events to audit-service; `tools/redaction.py` / `url_redaction.py` scrub credential-shaped spans before response/audit emission (SPEC-009 fail-closed when redacted fraction exceeds threshold).
- Dependency direction: routes → gateway_service → registry/tool → external connector; core config/metrics/telemetry are leaf utilities consumed by all layers; policies and schemas are pure data contracts shared with `shared/shared-contracts`.
- External boundaries: callers are trusted platform services (agent-platform, execution-runtime) carrying delegated tokens with `aud=tool-gateway`; portal traffic terminates at platform-gateway (explicitly excluded per README).
