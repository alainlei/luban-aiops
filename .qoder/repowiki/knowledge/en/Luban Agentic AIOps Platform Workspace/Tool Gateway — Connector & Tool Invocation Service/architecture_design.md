Layered FastAPI application under `src/tool_gateway/`:
- Entry point: `main.py` boots via `uvicorn.run` with `GatewayRunSettings.from_env`; `app.py::create_app` builds the `FastAPI` instance, wires lifespan hooks (eager browser CDP connect), registers the HTTP request-id middleware, includes the router, and mounts metrics/telemetry.
- API layer (`api/routes/`): `health`, `tools`, `secrets` routes mounted through `api/router.py`; route handlers delegate to `services/gateway_service.py` which centralizes identity resolution (`resolve_request_identity`), policy enforcement (`enforce_policy`), and the invoke pipeline (`invoke_tool`).
- Services layer: `gateway_service.py` orchestrates token verification → policy evaluation → registry dispatch → redaction → audit emission; `policy_engine.py` loads the YAML bundle from `GATEWAY_POLICY_PATH` (or packaged default); `token_verifier.py` verifies JWTs locally against JWKS; `audit_emitter.py` is fire-and-forget to `audit-service`.
- Tools layer (`tools/`): `base.py` defines `BaseTool`, `ToolDefinition`, `ToolResult`; `registry.py` holds the `ToolRegistry` with risk-tier admission (`read`/`write`/`admin`) and mutating-tool gating; each connector (`k8s_connector`, `elastic_connector`, `skills_connector`, `incidents_connector`, `browser_connector`, `http_connector`, `secrets_connector`) implements `register_tools(registry)` and is conditionally wired in `_build_tool_registry` based on `GATEWAY_*` settings. Browser and secrets connectors additionally share app-lifecycle state (`app.state.browser_connector`, `app.state.secret_delivery_buffer`).
- Core cross-cutting: `config.py` (Pydantic settings), `metrics.py` (Prometheus counters), `observability.py` / `telemetry.py` (logging + OTLP), `request_context.py` (x-request-id / x-execution-id correlation).
- Schemas (`schemas/api.py`) and versioned metadata (`metadata.py`) are shared across layers.
Dependency direction is strictly inward: routes → services → tools/core; connectors never import routes or services directly.
