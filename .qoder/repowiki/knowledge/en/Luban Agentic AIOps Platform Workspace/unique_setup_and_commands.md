Root entry point is GNU make: `make verify` runs the full pre-commit/pre-push gate (all product tests, kustomize builds, policy validation/scenarios, version & secret-vocabulary checks, secret-delivery demo, portal vitest + prod build, crash-safety failure test); `make sync` installs uv deps across all Python products; `make build` produces coordinated images tagged from `VERSION` plus git sha/dirty stamp and writes `shared/platform-ops/gitops/dev-k8s/.images.env`; `make deploy` applies the dev-k8s overlay; `make e2e` runs the scripted demos against a deployed cluster requiring port-forwards for platform-gateway and identity-service.
