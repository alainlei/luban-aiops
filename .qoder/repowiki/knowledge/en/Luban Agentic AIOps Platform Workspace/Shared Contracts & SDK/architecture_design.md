Two sibling sub-packages with a one-way dependency: `shared/shared-contracts/` is the canonical contract surface (JSON Schema files under `schemas/`, YAML policy bundles under `policies/`, SQL migration artifacts under `sql/`, and Python validation scripts under `scripts/`), while `shared/shared-sdk/` is an empty placeholder whose README documents the intended boundary for generated/hand-written service clients, auth helpers, tracing utilities, and typed event producers/consumers built on top of those schemas. The contracts are versioned per domain — v1 chat/session/stream/tool-execution contracts coexist alongside v2 `agent-*` contracts that define the platform-owned boundary between `tool-gateway` and `agent-platform`. Policy evaluation is driven by `policy-default.yaml` validated against `policy-rule.schema.json` via `scripts/validate_policy.py`, with scenario coverage in `policy-scenarios.yaml` and diff tooling in `policy_diff.py`. The `skill-format.md` document is itself a machine-readable contract enforced by `schemas/skill.schema.json` and the skills-hub ingestion pipeline. Dependency direction is strictly inward: product modules consume these schemas; nothing inside this module imports product code.
