Runtime behavior is controlled entirely by environment variables: `PLATFORM_GATEWAY_*` for service URLs, auth tokens, timeouts, and feature flags (e.g. `PLATFORM_GATEWAY_REQUIRE_AUTH`, `PLATFORM_GATEWORK_POLICY_PATH`); `OTEL_ENABLED` toggles the OpenTelemetry push pipeline; `LOG_LEVEL` overrides the root logger severity; `OTEL_EXPORTER_OTLP_ENDPOINT` and `OTEL_EXPORTER_OTLP_HEADERS` configure the OTLP destination and authentication.
