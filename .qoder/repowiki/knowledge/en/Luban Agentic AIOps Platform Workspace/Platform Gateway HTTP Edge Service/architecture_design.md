The entrypoint `main.py` boots via uvicorn using `GatewayRunSettings.from_env()`, which instantiates the FastAPI app in `app.py`. The app factory wires cross-cutting concerns (structured logging, Prometheus metrics, OpenTelemetry) and registers a single middleware that injects `x-request-id` into every request. Route handlers live under `api/routes/` and are mounted through `api/router.py`; each handler delegates identity resolution, policy evaluation, and upstream proxying to services under `services/` (`agent_client`, `delegation_client`, `incident_client`, `skills_hub_client`, `tool_gateway_client`, `policy_engine`, `policy_matrix`, `token_verifier`). Policy decisions come from the policy engine module (YAML bundles + role×action matrix), while token delegation is handled by exchanging user tokens for short-lived delegated tokens before proxy calls. The `schemas/api.py` Pydantic models provide the shared contract between routes and services.
