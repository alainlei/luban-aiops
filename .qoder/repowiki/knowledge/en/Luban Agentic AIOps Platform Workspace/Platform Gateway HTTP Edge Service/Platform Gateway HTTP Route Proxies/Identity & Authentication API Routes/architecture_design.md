Two thin FastAPI `APIRouter` modules (`identity.py`, `auth.py`) each declare a single `router = APIRouter()` instance with HTTP handlers that delegate all business logic to `platform_gateway.services.gateway_service` (e.g. `normalize_identity`, `start_login`, `complete_login`, `refresh_token`, `build_logout_url`). Cross-cutting concerns — settings injection via `get_settings`, request-ID extraction via `resolve_request_id`, and structured audit logging via `log_event` — are imported from `core.*`. The `auth` module additionally performs inline bearer-token parsing and delegates token verification to `platform_gateway.services.token_verifier.verify_token`, raising `TokenVerificationError` on failure. Both routers are composed into the application by `api/router.py`, which creates a top-level `APIRouter` and calls `include_router` for every feature subpackage; `auth.router` is included before `identity.router`, establishing mount order but no dependency between them.
