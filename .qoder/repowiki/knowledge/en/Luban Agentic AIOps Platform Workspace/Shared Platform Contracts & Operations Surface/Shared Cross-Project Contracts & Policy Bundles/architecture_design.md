Pure data-contract module with no runtime code — consumers import schemas or load policies at build/deploy time.

- `schemas/` holds one JSON Schema per cross-project payload, all targeting `https://json-schema.org/draft/2020-12/schema` with a stable `$id` under `metasync.github.io/luban-aiops/schemas/`. Schemas are grouped by domain: portal/gateway chat (v1), agent-service v2 boundary (`agent-*`), identity (`identity-token`, `identity-context`), policy (`policy-rule`, `policy-decision`, `policy-matrix`), tool execution (`tool-invocation`, `tool-result`), execution-runtime (`execution-request`, `execution-receipt`, `execution-observation`, `execution-recovery`, `execution-handoff-response`), audit, incidents, skills, model catalog, operations documents, session evidence, and streaming events. Backward compatibility is expressed inline via `oneOf` / optional fields rather than separate version files (e.g. `execution-request.schema.json` carries v2/v3 variants).
- `policies/` contains the canonical action-authorization bundle (`policy-default.yaml`, v1) plus scenario fixtures (`policy-scenarios.yaml`) and a password policy; evaluated by gateways as deny-by-default with precedence `deny > require_approval > allow` and higher `priority` wins within an outcome class.
- `scripts/` provides Python validators keyed to each contract family: `validate_policy.py` validates bundles against `policy-rule.schema.json` (enforcing version=1 and unique rule ids), `validate_password_policy.py`, `validate_policy_scenarios.py`, `sync_execution_contracts.py`, `validate_secret_vocabulary.py`, `policy_diff.py`, `validate_version.py`.
- `sql/execution-ledger-v1.sql` is the only DDL artifact, representing the durable ledger schema for execution records.
- `README.md` is the authoritative contract index and convention doc; `observability-conventions.md` and `skill-format.md` document cross-cutting conventions consumed by other modules.
- Dependency direction is outward-only: this module has no imports from product code; it is consumed by `products/` services and `shared/shared-sdk`.
