`make validate-dashboards` (or `python3 shared/platform-ops/dashboards/validate_dashboards.py`) runs the offline gate against the repo root. Live import requires port-forwarding `svc/openobserve-router` and exporting `OO_ROOT_USER_EMAIL`/`OO_ROOT_USER_PASSWORD` (same creds as `sync-otel-secrets.sh`), plus optional `OO_ENDPOINT`/`OO_ORG`/`OO_FOLDER`; run as an operator step, not part of `make verify`.
