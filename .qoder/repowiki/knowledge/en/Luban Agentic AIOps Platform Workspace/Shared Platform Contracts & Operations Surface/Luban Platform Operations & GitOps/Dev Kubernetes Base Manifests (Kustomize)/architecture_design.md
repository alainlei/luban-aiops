Single Kustomize base (`kustomization.yaml`) under `dev-k8s/base/` that declares a `dev-luban-aiops` namespace and aggregates one sub-directory per platform component: `platform-gateway`, `tool-gateway`, `agent-platform`, `identity-broker`, `audit-service`, `skills-hub`, `incident-service`, `execution-runtime`, and `operator-portal`. Each component directory follows a uniform layout of `<svc>-deployment.yaml`, `<svc>-service.yaml`, plus optional `runtime-config.env`, `runtime-secrets.env`, and `runtime-secrets.example.env`. Shared runtime configuration is merged via `configMapGenerator` into a single `platform-runtime-config` ConfigMap from all components' `runtime-config.env` files; policy documents are merged into a `platform-policy` ConfigMap sourced from `shared/policy.yaml` and an external `password-policy.yaml`. Infrastructure stateful services live in `infra/` (PostgreSQL StatefulSet + Service, Redis Deployment + Service, and SQL init scripts for skills/incidents/sessions). The base targets `imagePullPolicy: IfNotPresent` with images tagged `dev-local`, enabling local development without registry access. RBAC definitions are co-located with their consuming gateway components rather than centralized.
