The module is an operations bundle rather than a runtime package: `gitops/dev-k8s/` provides the Kustomize base layer (nine workloads plus Postgres/Redis in the `dev-luban-aiops` namespace), while `gitops/runtime-profiles/` composes provider posture overlays (LLM catalog, mutating-tools, browser web-check) into the shared `platform-runtime-config` ConfigMap consumed by agent-service. Both layers are wired together through Kustomize's overlay model so the active profile stays reviewable and Git-diffable. Cross-cutting operational assets live alongside the manifests: `dashboards/` ships versioned OpenObserve dashboard JSON with an offline validator and live importer (SPEC-065 R-3), `skills/` provides runbooks and alert-to-runbook mappings ingested by the skills hub, and `e2e/` scripts exercise the deployed gateway/identity broker/services against a live cluster. A set of `gitops/sync-*.sh` helpers (audit, email, delegation, sessions DB, secrets, etc.) keep external secret stores in sync with the cluster state. The module owns deployment and observability concerns only; business logic lives in `products/`, and runtime configuration contracts are defined in `shared/shared-contracts` / `shared/shared-sdk`.
