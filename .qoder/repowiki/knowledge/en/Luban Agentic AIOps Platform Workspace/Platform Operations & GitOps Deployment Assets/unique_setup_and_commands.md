`make validate-dashboards` runs `python3 shared/platform-ops/dashboards/validate_dashboards.py` to verify dashboard JSON schema and metric references without touching a cluster. Live import requires `OO_ROOT_USER_EMAIL`/`OO_ROOT_USER_PASSWORD` and `sh shared/platform-ops/dashboards/apply-dashboards.sh`. Runtime profile switching goes through `gitops/select-runtime-profile.sh`, which preserves `mutating-dev` and `browser-dev` postures when toggling LLM profiles.
