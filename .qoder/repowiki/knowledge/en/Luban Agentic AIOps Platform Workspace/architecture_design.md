The root is a workspace aggregator: `Makefile` enumerates every product in `products/` (agent-platform, audit-service, execution-runtime, identity-broker, incident-service, platform-gateway, skills-hub, tool-gateway, operator-portal) and delegates per-product `sync/test/lint/build/push` to each product's own `Makefile`, while owning cross-cutting concerns that tie them together — coordinated image tagging from the root `VERSION` file into `.images.env`, policy bundle sync from `shared/shared-contracts/policies/` into both `tool-gateway` and `platform-gateway`, kustomize overlay validation over `shared/platform-ops/gitops`, OpenObserve dashboard schema validation, secret-vocabulary lockstep checks, and the `make verify` pre-commit gate. Cross-product contracts live in `shared/shared-contracts/` (schemas, policies, SQL, scripts) and are consumed by multiple products; `docs/specs/` drives feature development via numbered SPEC documents with plan/spec/tasks triads validated against templates; `samples/acme-admin` is an out-of-band demo application deployed separately from the base overlay. The `mk/` fragments (`defaults.mk`, `image.mk`, `python.mk`) provide shared build defaults so root and per-product invocations resolve identically.
