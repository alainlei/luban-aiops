Backend selection is driven by `SESSION_STORE_BACKEND` (`memory` | `redis` | `postgres`; default `memory`). When set to `postgres`, `SESSION_DB_URL` is required; when set to `redis`, `SESSION_REDIS_HOST`/`SESSION_REDIS_PORT`/`SESSION_REDIS_DB` configure the connection. Unknown backend values raise at startup; reachable Redis/Postgres failures degrade to in-memory with a `session_store_fallbacks_total` metric.
