Three sibling service modules share a uniform backend-selection pattern: each exposes a `Protocol`-typed public interface (`EvidenceStore`, `OperationDocumentStore`) with an in-memory implementation and a Postgres implementation selected at runtime by the same `AGENT_STATE_STORE_BACKEND` / `AGENT_STATE_DB_URL` knobs used by the SPEC-017 state store.

- `evidence_store.py`: Per-session `tool_call`/`tool_result`/`secret_delivery` frame persistence. `_BaseEvidenceStore` centralizes size enforcement — per-entry truncation via `prepare_frames` and per-session budget eviction of oldest `tool_result.data` payloads — while subclasses implement row primitives (`_next_frame_index`, `_insert_rows`, `_session_bytes`, `_evict_oldest_result_payload`, `_load_rows`, `_delete_rows`). The Postgres backend uses a `session_evidence` table with opportunistic TTL sweep on writes; failures fall back to memory.
- `operation_documents.py`: Immutable document repository with one-way `draft -> published` lifecycle, owner-only visibility for drafts, and role-based `documents:read` visibility for published docs. Enforces `PER_OWNER_CAP=20` and `RETENTION_DAYS=30` via additive DDL migrations (`summary`, `blurb` columns). Publish is idempotent via `state = 'draft'` guard.
- `document_prose.py`: Optional LLM narrative layer driven by digest-only prompts (`_PROMPT_TEMPLATE` for shift handover, `_INCIDENT_PROMPT_TEMPLATE` for incident reports) that never sees raw transcripts or evidence payloads. `parse_blurb` extracts a bounded first-line `SUMMARY:` marker into the `blurb` field; generation is fail-soft (`prose_status=failed`) and bounded by `PROSE_TIMEOUT_SECONDS=30`. Uses the runtime's default model through `kernel._build_model`.

Dependency direction: `document_prose.py` depends only on `execution_recovery.EXECUTION_EVIDENCE_GUIDANCE` and the kernel's text extraction; the two stores are independent of each other and both depend only on `agent_service.core.metrics` and environment variables. Each module exports a module-level singleton (`EVIDENCE_STORE`, `OPERATION_DOCUMENT_STORE`) built by a `build_*` factory.
