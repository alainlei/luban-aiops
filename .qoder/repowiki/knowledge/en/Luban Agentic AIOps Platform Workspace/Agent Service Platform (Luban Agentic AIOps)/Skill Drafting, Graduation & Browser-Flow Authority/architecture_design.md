Three sibling services under `agent_service.services/` that share the Skill Format v1 Markdown contract but serve distinct lifecycle stages:

- `skill_draft.py` (SPEC-044/SPEC-045): two entry points — `build_skill_draft_bundle` for a session anchor and `build_incident_skill_draft_bundle` for an incident anchor. Both assemble a digest-only bundle (session digest via `shift_summary.build_digest`, plus validated triage report via `incident_client.fetch_incident_bundle`) and feed it to one bounded LLM call (`generate_skill_draft`, 30s timeout) whose fenced-contract output is parsed by `parse_model_output` and post-processed through `postprocess` (redaction + caps). Any failure degrades to a deterministic facts-only skeleton (`build_skeleton` / `build_incident_skeleton`) so generation never raises 500; nothing is persisted.
- `skill_graduation.py` (SPEC-055 R-4): no model call. `revalidate_blast_radius` re-applies gateway replay guards (step budget, origin allowlist, write-class declaration, credential-set references, secret-literal shape detection) against a captured trace and returns a `BlastRadius` dataclass; only if graduable does `build_executable_flow_draft` render the trace into a YAML-frontmattered Markdown runbook. The two constants `DEFAULT_MAX_GRADUATION_STEPS=20` and `MAX_STEPS_BYTES=65536` are deliberate twins of gateway/skills-hub defaults because products cannot import each other.
- `flow_approvals.py` (SPEC-051 R-1/R-2/R-6): in-memory, per-process stores `FLOW_CONTEXTS` (gateway flow binding reflection) and `FLOW_APPROVALS` (operator approval of first parked write), keyed by `session_id`. A `FlowContext.identity()` tuple `(skill_id, origin)` scopes the auto-signing authority; a rebinding to a different flow invalidates it, and `FLOW_KILLING_ERROR_CODES` drops both stores on gateway refusal codes. `BROWSER_WRITE_TOOLS` enumerates the mutable `web.*` surface gated by this path.

Dependency direction: `skill_graduation` imports `REDACTION_VALUE_PATTERNS`, `postprocess`, `provenance_block`, `slug_from_title` from `skill_draft` (shared redaction vocabulary and Markdown assembly); `skill_graduation` also imports `BROWSER_WRITE_TOOLS` from `flow_approvals`. Neither service persists — they produce Markdown strings consumed by routes that flip trace state and emit events.
