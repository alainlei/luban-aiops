- Model-driven fenced-contract parsing: LLM output is extracted via a regex fence (````skill-frontmatter`) and then strictly validated with a Pydantic model using `ConfigDict(extra="forbid")`, with any parse error falling back to a deterministic skeleton rather than raising.
- Deterministic degradation over exceptions: every external or model-dependent path wraps its body in a broad `except Exception` and logs + returns `None`, letting callers fall back to a format-valid skeleton so generation failures never become 500 responses.
- Shared redaction vocabulary as module-level constants: `REDACTION_VALUE_PATTERNS` is defined once in `skill_draft` and imported by `skill_graduation.revalidate_blast_radius` so draft redaction and graduation blast-radius detection use the same private-key/JWT/Bearer/AWS key patterns instead of diverging notions of what a secret looks like.
- Twin constants across product boundaries: gateway/skills-hub limits (`DEFAULT_BROWSER_FLOW_MAX_STEPS`, `ingestion.MAX_STEPS_BYTES`, `ingestion.MAX_STEP_TOOL_CHARS`) are copied as local defaults in this module with comments explaining why duplication is intentional — the gateway remains the enforcement authority at replay.
- Per-process singleton stores keyed by `session_id`: `FlowContextStore` and `FlowApprovalStore` expose `record/get/clear/clear_all` over internal `_by_session` dicts, with TTL expiry checked lazily on lookup so expired entries fail safe (return `None`) without eager eviction.
- YAML frontmatter emitted by hand-rolled string formatting with `json.dumps(..., ensure_ascii=False)` quoting for every scalar, avoiding a YAML library dependency while guaranteeing round-trip safety since JSON is a YAML subset.
