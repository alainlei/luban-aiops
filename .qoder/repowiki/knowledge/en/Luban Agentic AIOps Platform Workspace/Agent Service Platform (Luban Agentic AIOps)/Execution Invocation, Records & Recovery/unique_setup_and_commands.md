Production requires a Postgres connection sharing the agent state database; `AGENT_STATE_STORE_BACKEND=postgres` mandates `AGENT_STATE_DB_URL`. The Postgres table `execution_records` is created on first use by `PostgresExecutionRecordStore.initialize()` (same migration posture as confirmation records), and rows older than `RETENTION_WINDOW_DAYS` (default 30) are swept at startup and opportunistically on writes.
