The product ships a Vite+React SPA under `web-ui/app` built into static assets and served by nginx (`Dockerfile`, `nginx.conf`). Runtime layering inside `src/`:
- `main.tsx` bootstraps React 19 with Ant Design's `ConfigProvider` theme and an `AuthProvider`.
- `App.tsx` is the shell: it owns navigation state, renders a sidebar menu grouped into Control / Workspace sections, and dispatches to view components based on a `ViewId` union. It instantiates two independent `useSessionWorkspace` instances — one for operation mode (Chat, Incidents, Documents, Settings) and one gated behind `STUDIO_ROLES` for development mode (Studio), keeping session pointers separate.
- `auth/AuthContext.tsx` + `oidc.ts` + `storage.ts` implement OIDC login/logout/token refresh; `roles.ts` centralises role-set constants (`AUDIT_ROLES`, `INCIDENT_VIEW_ROLES`, `APPROVAL_DECIDER_ROLES`, `DOCUMENT_ROLES`, `SKILL_GRADUATE_ROLES`, `STUDIO_ROLES`) consumed via `hasAnyRole`.
- `api/client.ts` is the single HTTP entry point: every request adds `x-request-id` and a Bearer token from the auth session, resolves the gateway URL from localStorage override or current origin, and wraps failures in `ApiError` carrying server-supplied `detail` text.
- Feature modules are organised as sibling directories (`chat/`, `stream/`, `sessions/`, `views/{audit,control,incidents,workspace}`, `voice/`); each feature groups its React components, domain helpers, and Vitest suites colocated under `__tests__/`.
- Build-time injection in `vite.config.ts` defines `__PLATFORM_VERSION__`, `__REACT_VERSION__`, `__ANTD_VERSION__` from the repo root `VERSION` file and `package-lock.json`; production output goes to `web-ui/dist` consumed by the nginx stage.
- The Makefile delegates all build/test work to npm scripts (`make test` → `vitest run`, `make web-build` → `tsc --noEmit && vite build`); there is no Python/uv toolchain for this product.
