Build and test live under `products/operator-portal/web-ui/app` via npm (Node ≥22.22.2 per `.nvmrc`): `npm run dev` starts Vite with `/api` proxied to `http://localhost:8080`; `npm run build` runs typecheck then produces `web-ui/dist`; `npm run test` runs the full Vitest suite. From the product root, `make test` and `make web-build` wrap these. The Docker multi-stage build copies the repo-root `VERSION` file so `vite.config.ts` can read `../../../../VERSION` and inject `PLATFORM_VERSION` at compile time.
