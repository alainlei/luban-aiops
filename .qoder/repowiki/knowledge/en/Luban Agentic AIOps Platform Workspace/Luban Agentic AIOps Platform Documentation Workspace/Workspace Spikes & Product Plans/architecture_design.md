This module is a documentation-only scope under `docs/workspace/` that records the platform's transition from a monorepo into a modular workspace. The core design set consists of: `workspace-model.md` (proposed `products/` + `shared/` layout with eight product projects — operator-portal, agent-platform, policy-center, identity-broker, skills-hub, platform-gateway, tool-gateway, execution-runtime — plus shared-contracts/shared-sdk/platform-ops), `product-boundaries.md` (responsibility matrix, ownership groups, and explicit boundary rules such as 'no execution path bypasses policy'), `backend-service-layout-convention.md`, `python-container-strategy.md`, `repository-reorganization-plan.md`, and `github-repository-governance.md`. The remainder are time-boxed technical spikes (`*-spike.md`) that evaluate specific directions (AgentScope compression, MCP exposure/ingestion, long-term operator memory, semantic skill retrieval, session handover, shared SDK extraction, policy approval/rollout, portal framework rebuild, hitl bridging, observability dashboards, machine-consumer credentials) and explicitly record assessment-only outcomes without authorizing implementation. Two evaluation artifacts accompany the semantic-skill spike: `semantic-skill-retrieval-eval-set.md` (18-document catalogue, 63 audit queries, labeling protocol, metrics, pre-registered decision rule) and `semantic-skill-retrieval-labels.json` (label sheet). Dependency direction is one-way: spikes reference the workspace model and product boundaries as their architectural baseline; no code lives in this directory.
