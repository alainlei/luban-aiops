Entry point is the installed console script `platform-gateway` (maps to `platform_gateway.main:run`); development uses `uv` (see `pyproject.toml` `[dependency-groups] dev` with pytest/jsonschema). The package requires Python ≥3.11 and is built with `uv_build>=0.8.14,<0.9.0`. Runtime behavior is controlled entirely through `PLATFORM_GATEWAY_*` / `AGENT_SERVICE_URL` / `IDENTITY_*` / `PLATFORM_GATEWAY_AUDIT_*` / `PLATFORM_GATEWAY_INCIDENT_*` / `PLATFORM_GATEWAY_SKILLS_*` environment variables defined in `core/config.py`.
