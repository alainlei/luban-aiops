Layered FastAPI application with a clear request flow:
- Entry point: `main.py` boots uvicorn via the `platform-gateway` console script; `app.create_app()` wires logging, a per-request middleware that injects `x-request-id`, Prometheus metrics, and OpenTelemetry.
- Routing: `api/router.py` aggregates one module per concern under `api/routes/` (health, runtime, auth, identity, sessions, chat, audit, incidents, policy, tools, skills, models, approvals, documents).
- Business layer: `services/gateway_service.py` is the central orchestrator — it resolves identity (local JWT verify or synthetic dev user), evaluates action authorization through `services/policy_engine.py` against the YAML bundle in `policies/policy-default.yaml`, emits audit events via `audit_emitter`, then delegates downstream calls to specialized clients (`agent_client`, `delegation_client`, `incident_client`, `skills_hub_client`, `tool_gateway_client`).
- Configuration: `core/config.py` defines a frozen dataclass `PlatformGatewaySettings` loaded from environment variables via `from_env()`, cached by `get_settings()` with `lru_cache(maxsize=1)`.
- Telemetry: `core/metrics.py` exposes Prometheus counters (`record_policy_decision`, `record_token_verification`); `core/telemetry.py` + `core/observability.py` configure OTLP exporters and structured logging.
- Dependency direction: routes → gateway_service → {policy_engine, token_verifier, audit_emitter, *_client}; clients depend only on httpx and settings, never on FastAPI types. Downstream services are all optional HTTP backends reached through typed async clients.
