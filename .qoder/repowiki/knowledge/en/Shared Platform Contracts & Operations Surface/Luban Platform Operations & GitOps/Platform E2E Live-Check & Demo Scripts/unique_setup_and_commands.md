Each cluster demo expects `kubectl` pointed at a dev cluster with port-forwards open for `svc/platform-gateway 18083:8000` and `svc/identity-service 18081:8000`; defaults can be overridden via `GATEWAY_URL`, `IDENTITY_URL`, `NAMESPACE`, `TEST_USER`, etc. `observability-livecheck.sh` additionally needs `OO_ROOT_USER_EMAIL`/`OO_ROOT_USER_PASSWORD` for OpenObserve Basic auth and the `--live` mode with `LUBAN_OBS_DRIVE_PAID_TURN=1` triggers a billable deepseek call. `execution-failure-test.sh` accepts no arguments and exits with status 2 if `docker` or `uv` are missing.
